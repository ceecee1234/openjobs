      常见问题

      职位从哪里来？

      来自公开的招聘页面与社区投稿。每条职位都会附上原始链接，方便你直接访问原文。

      为什么有些职位没有薪资？

      薪资只在原始发布中明确给出时才会展示，我们不会估算或补充。

      怎样提交职位？

      点击上方“投稿职位”，在 GitHub 上提交一个模板 Issue 即可。请确保职位真实、合规，并附上原始链接。

      如何筛选？

      可以用顶部的方向标签、搜索框，或右上角的公司与地点下拉菜单组合筛选。筛选条件会保存在网址中，便于分享。
